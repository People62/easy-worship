# El-Gibbor Worship

Aplikasi desktop untuk menampilkan lirik lagu, ayat Alkitab, dan media ke layar saat ibadah di GPdI El-Gibbor. Berjalan offline di Windows.

> Status: dalam pengembangan, belum ada rilis.

## Dokumen

- [PRD](docs/PRD.md): kebutuhan produk
- [Rencana pengerjaan](docs/PLAN.md): tahap 0–7 menuju MVP
- [Alur Git, CI, dan rilis](docs/GIT-WORKFLOW.md)

## Konten berhak cipta

Repo ini tidak menyimpan lirik lagu, terjemahan Alkitab (misalnya TB/LAI), logo gereja, atau media. Semua itu diimpor sendiri oleh pengguna di komputernya.
